# Minisumo-Autonomo-con-PIC18f4550-Amateur
Minisumo autónomo amateur con PIC18F4550. Usa tres sensores ultrasónicos para detectar al oponente, dos QRD1114 para identificar el borde del dojo y un TB6612FNG para controlar los motores. Objetivo: diseñar un robot capaz de buscar, atacar y no salir del ring. Justificación: practica sensores, control y electrónica de potencia de forma accesible.
